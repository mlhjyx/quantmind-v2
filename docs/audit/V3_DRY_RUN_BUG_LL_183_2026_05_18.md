## §2 Root Cause

`scripts/run_paper_trading.py:482-493` (pre-fix):

```python
exec_result = exec_svc.execute_rebalance(
    conn=conn,
    strategy_id=settings.PAPER_STRATEGY_ID,
    exec_date=exec_date,
    target_weights=hedged_target,
    cb_level=cb.get("level", 0),
    position_multiplier=cb.get("position_multiplier", 1.0),
    price_data=price_data_t,
    initial_capital=settings.PAPER_INITIAL_CAPITAL,
    signal_date=signal_date,
    execution_mode=exec_mode,
)
```

**Missing `dry_run=dry_run` propagation**. `execute_rebalance` signature defaults `dry_run=False` (per `execution_service.py` line ~62), so live broker calls always fire regardless of script flag.

Same bug in line 466-474 `process_pending_orders(...)` call (also missing `dry_run=dry_run`).

## §3 Why This Bug Survived Until Now

- `--dry-run` was historically used with `execution_mode=paper` (PaperBroker, SimBroker internal — no real broker side effect).
- 真账户 live-fire path was never `--dry-run` tested **with valid signals** until tonight.
- Code reviewer / pre-push hooks 没 catch (silent runtime behavior, no assertion).

## §4 Fix Applied (Commit pending)

`scripts/run_paper_trading.py` 2 places:

```python
# Line 466-474 (process_pending_orders)
exec_svc.process_pending_orders(
    conn=conn,
    ...
    cb_level=cb.get("level", 0),
    dry_run=dry_run,              # ← LL-183 fix
    execution_mode=settings.EXECUTION_MODE,
)

# Line 482-494 (execute_rebalance)
exec_result = exec_svc.execute_rebalance(
    conn=conn,
    ...
    signal_date=signal_date,
    dry_run=dry_run,              # ← LL-183 fix
    execution_mode=exec_mode,
)
```

Ruff ✅ clean.
